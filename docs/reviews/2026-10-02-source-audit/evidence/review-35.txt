## S35-MASS：Northcott 证明所需的有限常数没有从原稿假设推出

- 分类：确认的原文证明缺口，严重程度 major；Lemma 3.5.5 的陈述需明确数值域，不宜笼统宣布为假。
- 位置：PDF **217**／印刷 **201**，Lemma 3.5.5 首个陈列式及其证明最后一项；同页 Claim 3.5.6 证明中四行系数高度估计，及紧接其后的“so that there are finitely many possibilities for F”一句。
- 相邻假设：PDF **215**／印刷 **199**，§3.5 开头只要求 proper adelic curve；PDF **216**／印刷 **200**，Definition 3.5.2 将 Northcott 性质定义为每个有限实数 C≥0 的高度子水平集有限。PDF **184**／印刷 **168**，§3.1 定义只要求每个非零元素的对数绝对值可测、可积及（proper 时）乘积公式；明确不要求参数映射单射或满射。PDF **185**／印刷 **169**，Proposition 3.1.2 只证明 κ 可积，另加 κ 在 Ω∞ 上有正下界时才推出 ν(Ω∞)<∞。

令 m=min(deg F+1,deg G+1)≥1。原式为

    h_S(FG) ≤ h_S(F)+h_S(G)+log(m) ν(Ω∞).

应严格区分以下读法：

1. 若 ν(Ω∞)<∞，该式作为实数不等式为真。
2. 若 ν(Ω∞)=∞，将右侧强行要求为有限实数是不合法的；特别 m=1 时还需说明 0·∞ 的约定。这是表达式的数值域问题，不能直接称为反例推翻了该不等式。
3. 在 [0,∞] 中，采用 0·∞=0，原式为真。m>1 时右侧是∞，不等式没有提供有限估计；m=1 时一个因子为非零常数，properness 的标量不变性给出所需结论。原稿证明最后写成常数函数的非负积分时，也自然得到这个解释。
4. 因此实质缺口出现在 Claim 3.5.6：原稿把

    h_S(F) ≤ δ C + (δ−1) log(2) ν(Ω∞)

   作为固定有限实数界来应用 Definition 3.5.2。δ>1 且质量∞时，这只说明系数高度≤∞；所有基域元素都符合这个无效上界，不能由 Northcott 性质推出有限多项式。

### 满足全部有关原文假设的例子

取 K=Q。记 V={∞}∪{所有素数}，标准绝对值为 |q|∞=|q|，|q|p=p^(−ord_p(q))。设

    Ω=V×{1,2,…},  A=P(Ω),  ν=计数测度,
    ε_n=2^(−n),  |q|_(v,n)=|q|_v^(ε_n).

这是原稿意义下的 proper adelic curve，且具有 Northcott 性质：

- 每个指数 ε_n 属于(0,1]，故通常实绝对值的 ε_n 次幂仍满足三角不等式；p-adic 绝对值的正次幂仍是非阿基米德绝对值。
- 全幂集使所有函数可测。对 q∈Q×，只有有限多个标准位满足 |q|v≠1，因此

      ∑_(v,n) |log |q|_(v,n)|
      = (∑_n ε_n) ∑_v |log |q|v|
      = ∑_v |log |q|v| < ∞.

  所有原稿要求的对数函数均绝对可积。
- ∑_n ε_n=1，由有理数通常的乘积公式（也可直接从素因子分解看出）得

      ∫Ω log |q|ω dν = ∑_v log |q|v = 0.

- 若 q=a/b 既约、b>0，则

      h_S(1:q) = ∑_(v,n) log max(1,|q|v^ε_n)
               = ∑_v log max(1,|q|v)
               = log max(|a|,b).

  这里 Definition 3.5.1 在代数闭包上定义的高度限制回 Q，等于基曲线的积分，因为每个扩张纤维有质量1。故高度≤C 的既约整数对满足 |a|,b≤exp(C)，只有有限多对；这直接证明 Northcott 性质，没有引用正在讨论的 Theorem 3.5.3。
- Ω∞={∞}×N_{≥1}，每一点质量1，故 ν(Ω∞)=∞；κ(∞,n)=ε_n，其他点κ=0，故

      A_S := ∫Ω κ dν = ∑_n ε_n = 1.

这个例子不是只在抽象测度空间上造“正可积函数支撑无限”的例子；它满足 §3.5 的 proper 与 Northcott 两项条件，排除了“Northcott 性质也许已隐含有限阿基米德质量”的解释。

### 最小修补及数学影响

保留可积指数，而不把它粗略放大成Ω∞的示性函数。对扩张位χ映到ω，局部绝对值为复嵌入的 κ(ω) 次幂，且有限系数卷积中至多有m项，故

    ||FG||χ ≤ m^κ(ω) ||F||χ ||G||χ.

κ 在代数扩张后由基底拉回，积分不变。积分后得到有限的实数估计

    h_S(FG) ≤ h_S(F)+h_S(G)+log(m) A_S,
    A_S=∫Ω κ dν <∞.

从而最小多项式的系数具有有限上界

    h_S(F) ≤ d h_S(1:α)+(d−1)log(2) A_S
           ≤ D C+(D−1)log(2) A_S,   D=floor(δ), C≥0, δ≥1.

原证明此后的有限系数组合、有限根集、有限多个仿射图的论证可继续使用。Theorem 3.5.3、Claim 3.5.6、Corollary 3.5.7 不需增加有限质量假设，也没有被本例推翻。若仅给 Lemma 3.5.5 增加 finite mass 而不改后续证明，则只能证明该附加假设下的 Northcott 结论，会不必要地削弱原定理。

### 不能归咎于原稿的 totalized-integral 误读

在上述同一个 proper Northcott 曲线上取 F=G=X+1。各位处F的系数最大值为1，所以 h_S(F)=h_S(G)=0；FG=X²+2X+1 在非阿基米德位系数最大值为1，在(∞,n)为2^ε_n，故 h_S(FG)=log2。

若在 Lean 中把无限质量先做 `ENNReal.toReal`（∞变成0），或把不可积的实值函数1在Ω∞上的 Bochner 积分直接用于 RHS（Mathlib totalization 返回0），就会错误得到 log2≤0。这个反例反驳的是这种过强的实数编码，不是按扩展实数解释的原稿 Lemma 3.5.5。当前 fe4feea 的 Lean 已把有限质量的实数版和无条件 ENNReal 版分开，并未犯此错误。
