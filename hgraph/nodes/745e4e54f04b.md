Put $|f|_\infty=\lambda(V_\infty(f))$. This is a nonarchimedean real
absolute value on $F$. It takes the value zero at zero and, for nonzero
$p,q\in k[T]$, satisfies $|p/q|_\infty=e^{\deg p-\deg q}$.
