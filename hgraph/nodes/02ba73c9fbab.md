Each $p_F$ is measurable for $\mathcal A_L$. The base projection
$\pi_{L/K}$ and every evaluation $x\mapsto |a|_x$, $a\in L$, are
$\mathcal A_L$-measurable. So is $x\mapsto\log|a|_x$, with the convention
$\log0=0$.
