A measurable real function $f$ on $\Omega_L$ is $\nu_L$-integrable
if and only if
\[
 \int_\Omega\left(\int_{X_\omega}|f|\,dP_{L,\omega}\right)d\nu<\infty,
\]
where both integrals in this criterion take values in $[0,\infty]$.
