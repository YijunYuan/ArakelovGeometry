If $S$ has the Northcott property, then for every $n\in\mathbb N$
and every $C,\delta\in\mathbb R$, the set
\[
 \{x\in\mathbb P^n(\overline K):
       h_S(x)\leq C,\ [K(x):K]\leq\delta\}
\]
is finite.
More generally, for any algebraic extension $L/K$ and finite nonempty
index set $I$, the set of $x\in\mathbb P(L^I)$ satisfying
$h_{S\otimes_K L}(x)\leq C$ and $[K(x):K]\leq\delta$ is finite.
