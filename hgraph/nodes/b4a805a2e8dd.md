For a function $F:\Omega_L\to\mathbb R$, define
\[
 \mathcal M_{L/K}F(\omega)=\max_{x\in X_\omega}F(x).
\]
Each fibre is finite and nonempty, so this is a finite real number and
the maximum is attained. It is the least upper bound of the values of
$F$ on $X_\omega$.
